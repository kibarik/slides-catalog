# Каталог презентаций — правила для агентов

Сайт `slides.aleksishmanov.ru` раздаётся как есть, без сборки: что в `main`, то и видят зрители.
Колода — `<id>/index.html`, стейдж 1280×720, листается стрелками. Подробности — `README.md`.

## Обязательно при любой правке колоды

1. **Телефон.** Стейдж `#stage { flex: none }`; режим ленты `@media (max-width: 700px), (orientation: portrait) and (max-width: 900px)` — слайды друг под другом без масштаба; JS знает о телефоне через `matchMedia`; `#slide=N` прокручивает к слайду. Новые стили слайда — с правилом для телефона в том же коммите. На десктопе масштаб и центр считать по `document.documentElement.clientWidth/clientHeight` (без полосы прокрутки), стейдж — `position: fixed` с `left/top` из `fit()`, иначе в окне с полосой прокрутки слайд съезжает вбок (пример — `sprint-under-manager`).
2. **Скорость.** Картинки — файлами `img/*.webp` с `loading="lazy"`, не base64. Демо — `demo/*.html` через `data-src`, грузится на своём слайде, на телефоне — по кнопке «На весь экран». `index.html` ≤ 300 КБ.
3. **Сборка с нуля.** Генератор колоды берёт стили из своего источника, а не из уже собранного `index.html` — иначе CSS дублируется при каждом запуске. Два запуска подряд дают один и тот же файл.
4. **Проверка перед PR:**
   ```bash
   python3 tools/check_decks.py
   python3 -m http.server 8080 & BASE=http://localhost:8080 node tools/check_mobile.mjs
   ```
   Обе зелёные. Те же проверки идут в CI на каждый PR. Исключение — только строкой с причиной в `tools/deck-exceptions.json`.
5. **Публичные данные.** Примеры из работы — только обезличенные: вымышленные люди, команды, ключи задач.
