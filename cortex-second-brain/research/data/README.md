# Данные эксперимента

- `prompt-A.txt`, `prompt-C.txt`, `prompt-B.txt` — промпты условий: заметки, заметки + методология, Кортекс.
- `answers/` — ответы: A1–A3, C1–C3, B1–B3 (чистый корпус), Abig1–3, Bbig1–3 (зашумлённый корпус).
- `runs.json` — шаги агента, время, токены по каждому прогону.
- `rubric.txt` — эталон фактов и рубрика судьи; `judge-blind-key.json` — соответствие слепых номеров наборам.
- `judge-scores.json` — оценки судьи, два прохода (`<набор>|<проход>`), без ручной сверки.
- `markers.json` — объективные маркеры по тексту ответов.

Сценарий, команды и люди вымышлены. Исследование: `../index.html`.
