ДЛЯ ВНЕДРЕНИЯ

Как поставить
на поток

Один раз настроить — дальше цикл крутится сам, каждый день.

Техническая архитектура

① Сборщик

Читает Jira по таймеру 08:30 и по кнопке. Без ИИ.

② Отчёт PO

Эпики, риски, метрики, заметки — в мессенджере.

③ Факт спринта

Итог по целям квартала из Confluence — для комитета.

④ ИИ-агент

План правок по заметкам. В Jira пишет сервис после ✅.

Процесс: PO и техлиды

① 08:30 — сбор

Сборщик читает трекер и обновляет отчёт.

② Утро — пульс

PO видит все команды, техлид — свою.

③ День — комментарии

Вопросы и контекст — заметкой к эпику.

④ Синк — 5 минут

PO и техлиды обсуждают только блокаторы.

⑤ После — ИИ-правки

Агент предлагает правки, PO подтверждает ✅.

⑥ Конец спринта — факт

Комитет читает итог по целям и PDF.
